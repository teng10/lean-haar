1.4.2 Pauli twirling

The end goal of this section is to prove the Irrep Group Averaging Corollary

\begin{equation} \langle X \rangle _{G} = \frac{1}{d} \text{Tr}[X] I, \end{equation}
48

where \(n_a = d\) is the dimension of the vector space of the representation. To illustrate this, we first consider the group average of the single-qubit Pauli group on some arbitrary initial state \(\rho \).

Remark 1.4.3 Pauli groups

We denote the single-qubit Pauli group as

\begin{equation} G = \{ \pm (i) \sigma _{x}, \pm (i) \sigma _y, \pm (i) \sigma _z, \pm (i) I\} , \end{equation}
49

where the Pauli matrices are given by

\begin{equation} \sigma _0 = I = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \sigma _{x} = X = \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}, \sigma _y = Y = \begin{bmatrix} 0 & -i \\ i & 0 \end{bmatrix}, \sigma _z = Z = \begin{bmatrix} 1 & 0 \\ 0 & -1 \end{bmatrix}. \end{equation}
50

We note the following useful expressions.

Definition 1.4.4 Bloch vectors

Twirling.Physlib.blochStateFor any single-qubit quantum state \(\rho \), we can write it in terms of its Bloch vector,

\begin{equation} \rho = \frac{1}{2} (I + r \cdot \sigma ), \end{equation}
51

where \(r = (r_x, r_y, r_z) \in \mathbb {R}^3\) is the coordinate of the quantum state on the Bloch sphere and \(\sigma = (\sigma _x, \sigma _y, \sigma _z)\) is a three-tuple of the Pauli operators.

Remark 1.4.5 Pauli group identities

For all non-identity \(\sigma _{i}, \sigma _{j}\) in the Pauli group where \(i \neq j\), the following three statements are true.

  1. \(\sigma _{i}\sigma _{j} \sigma _{i} = - \sigma _j\),

  2. \( \sigma _{j}^3 = \sigma _{j}\), and

  3. \(\sigma _i^2 = \sigma _i\), since \(\sigma _i\) is represented by a self-adjoint matrix.

We want to show the following simpler equivalence using matrix computations.

Theorem 1.4.6 Pauli twirling of a single qubit

Twirling.Physlib.twirl_single_qubitrm:BlochVector For an arbitrary single-qubit state \(\rho \),

\begin{equation} \langle \rho \rangle _{G} = \frac{1}{N} \sum _{g} R(g) X R(g)^{\dagger } = \frac{I}{2}, \end{equation}
52

the maximally mixed state (since it is proportional to the identity matrix).

Proof ▼

Note that \(G\) has order \(N = 4\). For any Pauli operator \(\pm (i) X \in G\), \(X\) is self-adjoint. Thus, we have that

\begin{equation} \pm (i) X \rho (\pm (i) X)^{\dagger } = (\pm i) (\mp i) X \rho X = X \rho X. \label{eq:SimplifiedSigmaRhoSigma*} \end{equation}
53

By Def. 1.4.1 and Eq. 53,

\begin{equation} \langle \rho \rangle _{G} = \frac{1}{4} \left( \sigma _{x} \rho \sigma _{x} + \sigma _{y} \rho \sigma _{y} + \sigma _{z} \rho \sigma _{z} + I \rho I \right). \end{equation}
54

By Remark 1.4.4 and Remark 1.4.5, we can rewrite \(\rho \) such that

\begin{equation} \begin{split} \langle \rho \rangle _{G} = \frac{1}{4} \left( \sigma _{x} (\frac{1}{2} (I + r \cdot \sigma ) \sigma _{x} + \sigma _{y} (\frac{1}{2} (I + r \cdot \sigma )) \sigma _{y} + \sigma _{z} (\frac{1}{2} (I + r \cdot \sigma )) \sigma _{z} + I (\frac{1}{2} (I + r \cdot \sigma )) I \right)\\ = \frac{1}{4} \left( \frac{1}{2} \left[ \sigma _x I \sigma _x + r_x \sigma _x^3 + r_y \sigma _x \sigma _y \sigma _x + r_z \sigma _x \sigma _z \sigma _x \right] + \frac{1}{2} \left[ \sigma _y I \sigma _y + r_x \sigma _y \sigma _x \sigma _y + r_y \sigma _y^3 + r_z \sigma _y \sigma _z \sigma _y \right] \right.\\ + \frac{1}{2} \left[ \sigma _z I \sigma _z + r_x \sigma _z \sigma _x \sigma _z + r_y \sigma _z \sigma _y \sigma _z + r_z \sigma _z^3 \right] + \frac{1}{2} \left[ I^3 + r_x I \sigma _x I + r_y I \sigma _y I + r_z I \sigma _z I \right] \left. \right)\\ = \frac{1}{8} \left( \right. [I + r_x \sigma _x - r_y \sigma _y - r_z \sigma _z] + [I - r_x \sigma _x + r_y \sigma _y - r_z \sigma _z]\\ + [I - r_x \sigma _x - r_y \sigma _y + r_z \sigma _z] + [I + r_x \sigma _x + r_y \sigma _y + r_z \sigma _z ]\left. \right)\\ = \frac{1}{8}\left( 4I\right) = \frac{I}{2}. \end{split} \end{equation}
