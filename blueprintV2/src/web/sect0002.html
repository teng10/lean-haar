1.1 Definitions and Commutants

Let \(V = \mathbb {C}^d\) denote the \(d\)-dimensional complex Euclidean space (modeled as Fin d \(\to \) \(\mathbb {C}\)). We study the \(k\)-fold tensor power of \(V\) and the actions of the symmetric group \(S_k\) and the endomorphism algebra \(\text{End}(V)\) on it.

Definition 1.1.1 Tensor Power Space

SchurWeyl.TensVThe \(k\)-fold tensor power of \(V\) is defined as:

\begin{equation} V^{\otimes k} = \bigotimes _{i=1}^k V \end{equation}
1

Definition 1.1.2 Permutation Action

SchurWeyl.permActiondef:TensVGiven a permutation \(\sigma \in S_k\), the permutation operator \(W_\sigma \) on \(V^{\otimes k}\) acts by permuting the tensor factors:

\begin{equation} W_\sigma (v_1 \otimes \dots \otimes v_k) = v_{\sigma ^{-1}(1)} \otimes \dots \otimes v_{\sigma ^{-1}(k)} \end{equation}
2

Definition 1.1.3 Diagonal Action

SchurWeyl.diagActiondef:TensVGiven an operator \(g \in \text{End}(V)\), the diagonal action \(g^{\otimes k}\) on \(V^{\otimes k}\) acts as \(g\) on each tensor factor:

\begin{equation} g^{\otimes k}(v_1 \otimes \dots \otimes v_k) = g(v_1) \otimes \dots \otimes g(v_k) \end{equation}
3

Definition 1.1.4 Permutation Image

SchurWeyl.permImagedef:permAction, def:TensVThe permutation image \(\mathcal{P}_{d,k} \subseteq \text{End}(V^{\otimes k})\) is the set of all permutation operators:

\begin{equation} \mathcal{P}_{d,k} = \{ W_\sigma \mid \sigma \in S_k \} \end{equation}
4

Definition 1.1.5 Diagonal Image

SchurWeyl.diagImagedef:diagAction, def:TensVThe diagonal image \(\mathcal{D}_{d,k} \subseteq \text{End}(V^{\otimes k})\) is the set of all diagonal action operators:

\begin{equation} \mathcal{D}_{d,k} = \{ g^{\otimes k} \mid g \in \text{End}(V) \} \end{equation}
5

Lemma 1.1.6 Permutation Action on Simple Tensors

SchurWeyl.permAction_tproddef:permActionFor any simple tensor \(\bigotimes _{i} v_i\), we have:

\begin{equation} W_\sigma (\bigotimes _{i} v_i) = \bigotimes _{i} v_{\sigma ^{-1}(i)} \end{equation}
6

Lemma 1.1.7 Diagonal Action on Simple Tensors

SchurWeyl.diagAction_tproddef:diagActionFor any simple tensor \(\bigotimes _{i} v_i\), we have:

\begin{equation} g^{\otimes k}(\bigotimes _{i} v_i) = \bigotimes _{i} g(v_i) \end{equation}
7

Lemma 1.1.8 Action Commutativity on Simple Tensors

SchurWeyl.permAction_diagAction_tprodlem:permAction_tprod, lem:diagAction_tprod, def:diagAction, def:permActionFor any permutation \(\sigma \in S_k\), operator \(g \in \text{End}(V)\), and vector family \(v\):

\begin{equation} W_\sigma (g^{\otimes k}(v_1 \otimes \dots \otimes v_k)) = g^{\otimes k}(W_\sigma (v_1 \otimes \dots \otimes v_k)) \end{equation}
8

Theorem 1.1.9 Permutation-Diagonal Commutativity

SchurWeyl.permAction_diagAction_commlem:permAction_diagAction_tprod, def:diagAction, def:permActionFor any \(\sigma \in S_k\) and \(g \in \text{End}(V)\), the permutation action and diagonal action commute as endomorphisms:

\begin{equation} W_\sigma \circ g^{\otimes k} = g^{\otimes k} \circ W_\sigma \end{equation}
9

Theorem 1.1.10 Permutation Image Centralizes Diagonal Image

SchurWeyl.permImage_subset_centralizer_diagImagethm:permAction_diagAction_comm, def:permImage, def:diagImageThe permutation image is contained in the centralizer of the diagonal image:

\begin{equation} \mathcal{P}_{d,k} \subseteq \text{Comm}(\mathcal{D}_{d,k}) \end{equation}

Theorem 1.1.11 Diagonal Image Centralizes Permutation Image

SchurWeyl.diagImage_subset_centralizer_permImagethm:permAction_diagAction_comm, def:permImage, def:diagImageThe diagonal image is contained in the centralizer of the permutation image:

\begin{equation} \mathcal{D}_{d,k} \subseteq \text{Comm}(\mathcal{P}_{d,k}) \end{equation}
