2.2 Uniqueness and the Gram Matrix for \(k \le d\)

When the number of tensor factors \(k\) is at most the dimension \(d\), the permutation operators are linearly independent, which implies that the solution to the Weingarten system is unique.

Definition 2.2.1 Abstract Gram Matrix

SchurWeyl.gramMatrixThe Gram matrix of a family \(v\) is \(G_{j, i} = \langle v_j, v_i \rangle \).

Definition 2.2.2 Abstract Gram Target Vector

SchurWeyl.gramVecThe Gram target vector is \(u_j = \langle v_j, w \rangle \).

Theorem 2.2.3 Matrix Formulation of Gram System

SchurWeyl.isGramSolution_iff_mulVecdef:gramMatrix, def:gramVecA vector \(c\) solves the Gram system if and only if \(G c = u\).

Theorem 2.2.4 Invertibility of Independent Gram Matrix

SchurWeyl.gramMatrix_det_ne_zerodef:gramMatrixIf the vectors \(v_1, \dots , v_n\) are linearly independent, then their Gram matrix is invertible.

Theorem 2.2.5 Unique Gram Solution

SchurWeyl.gram_solution_eq_invthm:isGramSolution_iff_mulVec, thm:gramMatrix_det_ne_zeroIf the vectors are linearly independent, the Gram system has a unique solution given by \(c = G^{-1} u\).

We apply this to permutation operators.

Theorem 2.2.6 Linear Independence of Vectorized Permutations

SchurWeyl.linearIndependent_endVec_permOpdef:endVec, def:permOpFor \(k \le d\), the vectorized permutation operators \(\text{endVec}(V_d(\sigma ))\) are linearly independent.

Theorem 2.2.7 Linear Independence of Permutation Operators

SchurWeyl.linearIndependent_permOpthm:linearIndependent_endVec_permOpFor \(k \le d\), the permutation operators \(V_d(\sigma )\) are linearly independent in \(\text{End}(V^{\otimes k})\).

Definition 2.2.8 Weingarten Gram Matrix

SchurWeyl.weingartenGramdef:permDual, def:permOpThe Weingarten Gram matrix is defined by \(G_{\sigma , \pi } = \text{Tr}(V_d^\dagger (\sigma ) V_d(\pi ))\).

Definition 2.2.9 Weingarten Target Vector

SchurWeyl.weingartenVecdef:permDualThe Weingarten target vector is \(u_\sigma = \text{Tr}(V_d^\dagger (\sigma ) O)\).

Theorem 2.2.10 Weingarten Gram as Vectorized Gram

SchurWeyl.weingartenGram_eq_gramMatrixdef:weingartenGram, def:gramMatrix, thm:inner_endVec_perm_eq_trace, def:endVec, def:permOpThe Weingarten Gram matrix is the Gram matrix of vectorized permutation operators.

Theorem 2.2.11 Weingarten Target as Vectorized Target

SchurWeyl.weingartenVec_eq_gramVecdef:weingartenVec, def:gramVec, thm:inner_endVec_perm_eq_trace, def:endVec, def:permOpThe Weingarten target vector is the Gram vector of vectorized permutation operators.

Theorem 2.2.12 Cycle Count Formula for Gram Entries

SchurWeyl.weingartenGram_eq_cardthm:inner_endVec_perm_eq_trace, def:permOpThe entry \(\text{Tr}(V_d^\dagger (\sigma ) V_d(\pi ))\) equals the number of index functions invariant under \(\sigma ^{-1}\pi \), which evaluates to \(d^{\# \text{cycles}(\sigma ^{-1}\pi )}\).

Theorem 2.2.13 Invertibility of Weingarten Gram Matrix

SchurWeyl.weingartenGram_det_ne_zerothm:weingartenGram_eq_gramMatrix, thm:linearIndependent_endVec_permOpFor \(k \le d\), the Weingarten Gram matrix is invertible.

Theorem 2.2.14 Unique Weingarten Solution

SchurWeyl.weingarten_solution_uniquethm:linearIndependent_endVec_permOp, thm:weingartenGram_eq_gramMatrix, thm:weingartenVec_eq_gramVecFor \(k \le d\), the Weingarten system has a unique solution.

Theorem 2.2.15 Inverse Solution Form

SchurWeyl.weingarten_solution_eq_invthm:weingarten_solution_uniqueFor \(k \le d\), the unique coefficient vector is given by \(c = G^{-1} u\).
