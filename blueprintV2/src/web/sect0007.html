2.2 Uniqueness and the Gram Matrix for \(k \le d\)

When the number of tensor factors \(k\) is at most the dimension \(d\), the permutation operators are linearly independent, which implies that the solution to the Weingarten system is unique.

Definition 2.2.1 Abstract Gram Matrix

SchurWeyl.gramMatrixThe Gram matrix of a family \(v\) is \(G_{j, i} = \langle v_j, v_i \rangle \).

Definition 2.2.2 Abstract Gram Target Vector

SchurWeyl.gramVecThe Gram target vector is \(u_j = \langle v_j, w \rangle \).

Theorem 2.2.3 Abstract Gram Matrix Application

SchurWeyl.gramMatrix_applydef:gramMatrixThe entries of the Gram matrix satisfy \(\text{gramMatrix}(v)_{j, i} = \langle v_j, v_i \rangle \).

Theorem 2.2.4 Abstract Gram Target Application

SchurWeyl.gramVec_applydef:gramVecThe entries of the target vector satisfy \(\text{gramVec}(v, w)_j = \langle v_j, w \rangle \).

Theorem 2.2.5 Matrix Formulation of Gram System

SchurWeyl.isGramSolution_iff_mulVecdef:gramMatrix, def:gramVec, thm:gramMatrix_apply, thm:gramVec_applyA vector \(c\) solves the Gram system if and only if \(G c = u\).

Theorem 2.2.6 Invertibility of Independent Gram Matrix

SchurWeyl.gramMatrix_det_ne_zerodef:gramMatrixIf the vectors \(v_1, \dots , v_n\) are linearly independent, then their Gram matrix is invertible.

Theorem 2.2.7 Gram Matrix Determinant is a Unit

SchurWeyl.gramMatrix_isUnit_detdef:gramMatrix, thm:gramMatrix_det_ne_zeroIf the family of vectors is linearly independent, the determinant of its Gram matrix is a unit in \(\mathbb {C}\).

Theorem 2.2.8 Unique Gram Solution

SchurWeyl.gram_solution_eq_invdef:gramMatrix, def:gramVec, thm:isGramSolution_iff_mulVec, thm:gramMatrix_isUnit_detIf the vectors are linearly independent, the Gram system has a unique solution given by \(c = G^{-1} u\).

Definition 2.2.9 Abstract Gram Solution Set

SchurWeyl.gramSolutionSetThe set of all solution vectors \(c\) to the Gram system.

Theorem 2.2.10 Gram Solution Set is Singleton

SchurWeyl.gram_solutionSet_eq_singletondef:gramSolutionSet, def:gramMatrix, def:gramVec, thm:gramMatrix_isUnit_det, thm:gram_solution_eq_inv, thm:isGramSolution_iff_mulVecFor a linearly independent family of vectors, the solution set of the Gram system is the singleton containing \(G^{-1} u\).

Theorem 2.2.11 Uniqueness of Gram System Solution

SchurWeyl.gram_system_uniquethm:gram_system_solvable, thm:gram_solution_eq_invFor a linearly independent family of vectors, there exists a unique solution to the Gram system.

We apply this to permutation operators.

Definition 2.2.12 Matrix Entries Equivalence

SchurWeyl.matrixEntriesEquivThe linear equivalence between matrices and the function space of their entries.

Definition 2.2.13 Endomorphism Vectorization Equivalence

SchurWeyl.endVecEquivdef:toEndMatrix, def:matrixEntriesEquiv, def:TensVThe linear equivalence between endomorphisms and the Euclidean space of their matrix entries.

Definition 2.2.14 Linear Endomorphism Vectorization

SchurWeyl.endVecₗdef:endVecEquiv, def:TensVThe linear map representing the vectorization of endomorphisms.

Theorem 2.2.15 Linear Vectorization Application

SchurWeyl.endVecₗ_applydef:endVecₗ, def:endVecThe linear endomorphism vectorization matches the standard vectorization: \(\text{endVec}_\ell (O) = \text{endVec}(O)\).

Theorem 2.2.16 Linear Vectorization is Injective

SchurWeyl.endVecₗ_injectivedef:endVecₗ, def:endVecEquivThe linear endomorphism vectorization is injective.

Theorem 2.2.17 Linear Vectorization Kernel

SchurWeyl.endVecₗ_kerdef:endVecₗ, thm:endVecₗ_injectiveThe kernel of the linear endomorphism vectorization is the trivial submodule.

Theorem 2.2.18 Linear Independence of Vectorized Permutations

SchurWeyl.linearIndependent_endVec_permOpdef:endVec, def:permOp, lem:toEndMatrix_permActionFor \(k \le d\), the vectorized permutation operators \(\text{endVec}(V_d(\sigma ))\) are linearly independent.

Theorem 2.2.19 Linear Independence of Permutation Operators

SchurWeyl.linearIndependent_permOpdef:permOp, thm:linearIndependent_endVec_permOp, def:endVecₗ, thm:endVecₗ_applyFor \(k \le d\), the permutation operators \(V_d(\sigma )\) are linearly independent in \(\text{End}(V^{\otimes k})\).

Definition 2.2.20 Weingarten Gram Matrix

SchurWeyl.weingartenGramdef:permDual, def:permOp, def:TensVThe Weingarten Gram matrix is defined by \(G_{\sigma , \pi } = \text{Tr}(V_d^\dagger (\sigma ) V_d(\pi ))\).

Definition 2.2.21 Weingarten Target Vector

SchurWeyl.weingartenVecdef:permDual, def:TensVThe Weingarten target vector is \(u_\sigma = \text{Tr}(V_d^\dagger (\sigma ) O)\).

Theorem 2.2.22 Weingarten Gram as Vectorized Gram

SchurWeyl.weingartenGram_eq_gramMatrixdef:weingartenGram, def:gramMatrix, thm:inner_endVec_perm_eq_trace, def:endVec, def:permOp, thm:gramMatrix_applyThe Weingarten Gram matrix is the Gram matrix of vectorized permutation operators.

Theorem 2.2.23 Weingarten Target as Vectorized Target

SchurWeyl.weingartenVec_eq_gramVecdef:weingartenVec, def:gramVec, thm:inner_endVec_perm_eq_trace, def:endVec, def:permOp, thm:gramVec_applyThe Weingarten target vector is the Gram vector of vectorized permutation operators.

Theorem 2.2.24 Cycle Count Formula for Gram Entries

SchurWeyl.weingartenGram_eq_carddef:weingartenGram, def:endVec, lem:toEndMatrix_permAction, thm:inner_endVec_perm_eq_trace, def:permOpThe entry \(\text{Tr}(V_d^\dagger (\sigma ) V_d(\pi ))\) equals the number of index functions invariant under \(\sigma ^{-1}\pi \), which evaluates to \(d^{\# \text{cycles}(\sigma ^{-1}\pi )}\).

Definition 2.2.25 Natural Weingarten Gram Matrix

SchurWeyl.weingartenGramNatThe natural-number valued Weingarten Gram matrix whose entries are the coincidence counts.

Theorem 2.2.26 Weingarten Gram is NatCast

SchurWeyl.weingartenGram_eq_natCastdef:weingartenGram, def:weingartenGramNat, thm:weingartenGram_eq_cardThe complex Weingarten Gram matrix entries are cast from the natural-number valued Weingarten Gram matrix.

Theorem 2.2.27 Natural Weingarten Gram Diagonal

SchurWeyl.weingartenGramNat_diagdef:weingartenGramNatThe diagonal entries of the natural Weingarten Gram matrix equal \(d^k\).

Theorem 2.2.28 Invertibility of Weingarten Gram Matrix

SchurWeyl.weingartenGram_det_ne_zerodef:weingartenGram, thm:weingartenGram_eq_gramMatrix, thm:linearIndependent_endVec_permOp, thm:gramMatrix_det_ne_zeroFor \(k \le d\), the Weingarten Gram matrix is invertible.

Definition 2.2.29 Weingarten Solution Set

SchurWeyl.weingartenSolutionSetdef:weingartenGram, def:weingartenVec, def:TensVThe set of solution vectors \(c\) to the Weingarten system.

Theorem 2.2.30 Weingarten Solution Set is Singleton

SchurWeyl.weingarten_solutionSet_eq_singletondef:weingartenSolutionSet, def:weingartenGram, def:weingartenVec, thm:gram_solutionSet_eq_singleton, thm:linearIndependent_endVec_permOp, thm:weingartenGram_eq_gramMatrix, thm:weingartenVec_eq_gramVecFor \(k \le d\), the solution set of the Weingarten system is a singleton containing \(G^{-1} u\).

Theorem 2.2.31 Unique Weingarten Solution

SchurWeyl.weingarten_solution_uniquedef:weingartenVec, def:weingartenGram, thm:linearIndependent_endVec_permOp, thm:weingartenGram_eq_gramMatrix, thm:weingartenVec_eq_gramVec, thm:gram_system_uniqueFor \(k \le d\), the Weingarten system has a unique solution.

Theorem 2.2.32 Inverse Solution Form

SchurWeyl.weingarten_solution_eq_invdef:weingartenVec, def:weingartenGram, thm:weingarten_solutionSet_eq_singletonFor \(k \le d\), the unique coefficient vector is given by \(c = G^{-1} u\).
