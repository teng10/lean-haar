Definition 1.1.3symmetric subspace of linear operators

The symmetric subspace of linear operators \(\mathcal{L}(\mathcal{X})^{\@undefined k}\) is the set of all operators \(X \in \mathcal{L}(\mathcal{X}^{\otimes k})\) that remain unchanged (invariant) under the permutation \(W_{\pi }\). That is,

\begin{equation} \mathcal{L}(\mathcal{X})^{\@undefined k} = \{ X \in \mathcal{L}(\mathcal{X}^{\otimes k}) : X = W_{\pi } X W_{\pi }^{*} \text{ for all } \pi \in S_{k} \} . \label{eq:sym_Lk} \end{equation}
